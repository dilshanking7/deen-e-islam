YAHAN APNI PDF FILES DALEIN
===========================

Is folder (public/pdfs) mein apni PDF files inhi naam ke saath rakhein.
File ke naam bilkul inhi tarah hone chahiye taaki app unhe dhoond sake:

  1. qanun-e-shariyat.pdf        -> Qanun-e-Shariyat (Urdu)
  2. qanun-e-shariyat-new.pdf    -> Qanun-e-Shariyat (new)
  3. jannati-zevar.pdf           -> Jannati Zewar (Urdu)
  4. jannati-zevar-hindi.pdf     -> Jannati Zevar (In Hindi)
  5. essential-duas.pdf          -> Essential Duas in the Life of a Muslim

Example:
  Copy-Item "C:\MyPDFs\Qanun-e-Shariyat.pdf" "public\pdfs\qanun-e-shariyat.pdf"

PDF file dalne ke baad books page (app/books) par jaakar PDF Library
section se wo khul jayegi — search bar ke saath.
